# Bar Master shared generation contract (v2)
Create a comparative textbook, not just MCQs. Read existing chapter IDs and content first; keep stable issue IDs and increment revision only on changed content. Never replace a fuller existing chapter with a shorter summary. No paid API. Do not publish private question bank to public GitHub; export JSON for user import.
## Each issue
- One durable issue_id, subject, topic/title, mapping direct|partial|us_only|uk_only; separate exam-specific subject and syllabus reference. US MBE general law, CA essay distinctions, England & Wales SQE1; do not force mapping where none exists.
- Textbook sections: legal function, full rule, elements, burdens, exceptions and counterexceptions, temporal sequence, competing approaches, factual application, examples and counterfactuals, distinctions, exam pitfalls, authorities and law_as_of. English exam-ready rule + detailed Korean text. No lowering legal difficulty or omitting exam-relevant exceptions for brevity. Cover NCBE outline, CA written syllabus and SRA FLK1/FLK2 separately.
- Mindmap recursive {label,children}: real decision branches (yes/no), exceptions, legal outcomes, burden and timing, not just a decorative list.
- Flashcards: active recall of complete English rule sentences, Korean explanation, exception cards, comparison and missing-element drills. One idea per card, collectively exhaustive; not merely terminology.
- Questions: MBE 4 options, SQE1 5 options, original only unless official released and reuse rights verified. Realistic overlapping legal doctrines; plausible distractors; unique best answer; blind solve before checking original answer; source verification distinct from AI agreement. Same issue_id for mapped issues; separate IDs for each question. If no UK equivalent, mark us_only rather than inventing one.
- CA written: issue drill (5–15 minutes), issue spotting outline (10–20 minutes), full 60-minute essays including cross-topic facts, separate 90-minute performance tests using file/library and task memo. Prompts English, model answer English using IRAC with Korean commentary if desired. Rubric per issue and element, counterarguments, decisive facts, missing analysis, score not an official bar score. Do not give model answers before submission. CA-specific law only when question requires it. SQE1 does not test essays; SQE2 is a separate optional track, not disguised as SQE1.
